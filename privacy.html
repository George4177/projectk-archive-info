ProjectK Archive 隐私政策

生效日期：2026-11-06。本说明适用于账户所有者个人使用的ProjectK Archive桌面归档取回工具。

读取哪些信息

工具请求Google Drive只读授权，用于读取存储容量、已配置归档文件夹内清单登记文件的元数据及文件内容。Google的权限范围本身覆盖整个Drive；应用的实际请求按本地清单及配置限定。本工具不请求上传、修改或删除Drive文件的权限。

用途与保存位置

文件下载到用户电脑，进行完整性校验并恢复本地研究文件。校验记录包括文件标识、路径、摘要、大小、时间及成功或失败状态。OAuth凭据由本地客户端保存在本地配置中，不写入公开网站、Git源码仓库或归档校验报告。

共享与第三方

本工具直接使用Google Drive API和本地rclone客户端传输文件；不会销售用户数据，也不会自行将文件内容提供给广告或分析服务。用户随后在其他应用中处理恢复文件时，适用那些应用各自的数据处理规则。

本说明网站使用GitHub Pages托管。网站不设置应用登录表单、跟踪脚本或分析Cookie；托管提供方可能按自身政策处理通常的网页访问日志。网站不展示用户Drive文件或授权凭据。

保留与控制

本地缓存由用户或明确配置的清理操作管理；删除本地缓存不会删除Drive原件。用户可在Google账户的第三方连接设置撤销授权，也可停止工具并删除本地授权配置。工具不会自动扩大授权范围。

联系

请使用Google授权页面显示的应用支持邮箱联系应用所有者。不要在公开渠道发送OAuth密钥、令牌或私人文件。

English summary

ProjectK Archive is a personal desktop archive restoration tool. It requests read-only Google Drive access to check storage and retrieve files registered in a local manifest for a configured folder. The OAuth scope covers all Drive files; application requests are limited by that configuration. Downloads and credential configuration remain on the user's computer. Verification logs contain file identifiers, hashes, sizes, paths and outcomes, not OAuth credentials. The utility does not sell data or itself transmit archive contents to advertising or analytics services. Users can revoke access through Google Account settings and remove local credentials or cached files. This informational website is hosted by GitHub Pages and contains no application login or analytics scripts. Contact the support email displayed on the Google consent screen.
